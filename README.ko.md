### 🗺️ FTB Quests — 퀘스트 생성기 월드 (버전 0.6) — [🚀 실행하기](https://picadoni.github.io/ftb-quests-generator/0.6/)
* **업데이트 내용:**
  * 코드 전면 개편: 기존의 단순 빌더에서 진정한 의미의 완전한 퀘스트 생성기로 진화했습니다.
  * 퀘스트 생성기(Quest Generator) 엔진을 추가했습니다.
  * 모든 파일을 단일 `.zip` 아카이브로 원클릭 다운로드하는 기능을 추가했습니다.
  * 4개 언어 완벽 지원 *(초기부터 지원된 러시아어 외 추가)*:
    * 영어 (English)
    * 일본어 (Japanese)
    * 중국어 번체 (Chinese Traditional)
    * 중국어 간체 (Chinese Simplified)

> *월드(World) — 코어가 대폭 확장되고 4개의 새로운 언어가 추가되어 전 세계 플레이어들이 사용할 수 있게 되었다는 의미를 담았습니다.*

### 🗺️ FTB Quests — 퀘스트 빌더 워터폴 (버전 0.5) — [🚀 실행하기](https://picadoni.github.io/ftb-quests-generator/0.5/)
* **업데이트 내용:**
  * 보상 기능이 포함된 최초의 퀘스트 빌더.
  * 카테고리 버튼 추가: 무작위 퀘스트 생성, 건축 및 블록, 도구, 플레이어 스탯.
  * 무작위 퀘스트 체인 길이(3개~52개)를 조절할 수 있는 슬라이더를 추가했습니다.
  * 압축 없이 모든 파일을 직접 스트림 방식으로 다운로드합니다.
  * 퀘스트 챕터 이름을 자동 생성하는 템플릿 기능을 추가했습니다 (아직 템플릿 수는 적지만 기본적인 생성이 가능합니다).

> *워터폴(Waterfall) — 폭포수가 오직 한 방향으로만 흐르듯, 이 빌더의 데이터 역시 누구도 되돌릴 수 없는 일방향 흐름을 따른다는 의미를 담았습니다...!*

### 🗺️ FTB Quests — 인터랙티브 빌더 프로토타입 (버전 0.4) — [🚀 실행하기](https://picadoni.github.io/ftb-quests-generator/0.4/)
* **업데이트 내용:**
  * 디자인 전면 개편: 어둡고 낯선 배경에서 벗어나 밝고 종이 질감에 가까운 테마로 변경했습니다.
  * 해당 계열의 마지막 빌더 버전입니다.
  * 코드를 업데이트하고 미니 이미지를 추가했습니다 — 정확히는 순수 CSS만으로 이미지를 렌더링하려던 시도였으나, 그리 성공적이지는 못했습니다.
  * 새로운 카테고리 버튼 추가: `🍳 음식 요리`.

> *프로토타입(Prototype) — 이미지를 추가하려던 첫 번째 시도였으나, 결과물이 다소 기묘해 보여 이후 폐기되었다는 의미를 담았습니다.*
