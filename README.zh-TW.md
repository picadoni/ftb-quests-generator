# 🗺️ FTB Quests — 任務生成器

專為 **Minecraft FTB Quests** 模組打造的線上網頁任務生成工具，可快速建立任務線、章節、幾何佈局與獎勵配置。直接在瀏覽器中運行，支援自動生成 HEX-ID、難度調節以及一鍵打包下載 `.zip` 檔案。

* **作者:** [picadoni](https://github.com)
* **授權條款:** 《絕對》版授權協議 (Charityware) — 詳情請參閱 [`LICENSE`](./LICENSE) 檔案。
